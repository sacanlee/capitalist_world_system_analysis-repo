# 世界语言文化圈地图与人口统计（Language & Cultural Spheres of the World）

按 8 大语言文化圈（15 子圈）对世界各国着色/划线，给出 **2025 与 2055** 年人口及 2025 年出生人口统计。
数据：联合国《世界人口展望 2024》中方案（UN WPP2024 Medium variant）。全部输出中英双语。

- **英语圈**：纯英语子圈（含日耳曼语国家，26实体，含以色列）/ 英语+印度-雅利安（南亚，4）/ 英语+斯瓦西里（6）/ 英语-其他（埃塞俄比亚、南苏丹、越南，3）

- **俄语圈**：纯俄语（4）/ 泛俄语（5）
- **印尼-马来语文化圈**（4）

统计时计入所属每一圈（和 > 100%），总图以"底色+斜纹"表达（底色=主体语言大圈；

## 政治/口径处理（重要）

1. **台湾、藏南、阿克赛钦、喀喇昆仑走廊、南海诸岛及断续线**：中国边界整体弃用 NE 底图，
   改用**中国官方标准地图数据**（阿里 DataV，含台湾省、藏南、南海十段线），全部按中国官方地图绘制；
   非中国圈层的子圈图上中国按普通国家灰色显示（边界仍为官方口径）。
2. **中国人口 = 大陆+香港+澳门+台湾**（UN WPP 分列，2025 年合计 14.47 亿）。
3. **克里米亚**：NE 底图归俄罗斯，已按中国官方地图口径**改绘为乌克兰**（几何手术：移出 RUS 第13环）。
4. **克什米尔**：按中国官方地图口径标示为**印巴争议地区**（斜纹+虚线，Natural Earth 10m disputed areas 几何）。
5. 多圈国家底色规则：当地主体语言定底色（如马来西亚=马来色底+汉红斜纹；哈萨克斯坦=突厥橄榄底+紫斜纹）。

## 数据与复核

- 人口/出生：WPP2024 中方案（沿用既有 `pop_by_country_2015_2070.csv`——由 WPP 单岁人口汇总，
  与 WPP 公布值一致；出生来自 WPP2024 demo `Births` 列）。
- 世界总量：2025=82.32亿 / 2055=98.46亿；2025出生=1.324亿（=WPP demo World 行，独立复核一致）。
- `scripts/02_verify.py` 全部通过（各国加总、demo World 行对照、显式成员重算、占比重算、重点国家抽查）；
  四/五图另做像素级抽查（芬兰/印度/肯尼亚子圈色、马格里布条纹混合色等）。

## 口径说明

- 中国人口含港澳台；波多黎各(美属)、巴勒斯坦按联合国口径单列。
- 北塞浦路斯无联合国单列数据，仅地图标注（未计入统计）。
- 新加坡、科摩罗、巴林、佛得角、圣多美和普林西比在 110m 底图中过小，以圆点/饼图编号标注（①‐⑤）。
- 未列入清单的国家·地区（瑞士、泰国、波兰、斯里兰卡、蒙古、格鲁吉亚、亚美尼亚、塞尔维亚等）显示为灰色，
  统计中列入"未列入清单"行（2025 年 3.13 亿、3.80%）。
